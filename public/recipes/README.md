# Recipe image folder

This folder is ready for local recipe images later.

For this update, recipe images are sourced as remote YouTube thumbnail URLs in `src/data/recipes.js`, so you do not need to download or place image files here yet.

If Carnivore Companion/CarnivorousChef gives permission to use local copies, save them here and change each recipe image field from a YouTube thumbnail URL to a local path such as:

```js
image: '/recipes/steak-and-eggs.jpg'
```
